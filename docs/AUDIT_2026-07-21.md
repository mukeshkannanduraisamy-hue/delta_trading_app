## What was actually dangerous

The five CRITICAL issues compounded. The worst path:

1. An exit order times out → outcome unknown.
2. The double-sell guard reads `/v2/positions/margined`, which Delta documents
   as lagging **up to 10 seconds**, and it still shows the position open.
3. So a second market sell goes out — and orders carried **no `reduce_only`**.
4. A sell on a flat book does not no-op. It **opens a short**: 100 naked ATM
   options with no stop, no tracking, and unbounded loss on a call.

None of this required anything exotic — just one dropped packet.

## Fixes

| # | Severity | Issue | Fix |
|---|---|---|---|
| 1 | CRITICAL | Exits had no `reduce_only`; stale positions endpoint drove the double-sell guard | `reduce_only="true"` (string form) on every exit; `_exchange_size()` now uses real-time `/v2/positions?product_id=`; `size` coerced to int, `side`/`order_type` validated |
| 2 | CRITICAL | Event loop froze up to ~20 s/cycle — executor lock held across blocking REST, acquired from 3 coroutines | Published snapshot cache; async callers never touch the lock. Signed-call read timeout 20 s → 12 s |
| 3 | CRITICAL | Upstream Delta WS had no stale detection (`ping_interval=None`, no watchdog) | `ping_interval=20`/`ping_timeout=10` + 60 s message watchdog + jittered backoff to 60 s |
| 4 | CRITICAL | No `client_order_id` → timed-out entries silently dropped, leaving untracked stop-less positions | Idempotency key on every order + `_recover_by_coid()` resolving ambiguous submissions via `/v2/orders/client_order_id/` |
| 5 | CRITICAL | No min-time-to-expiry floor — would buy an option minutes before 12:00 UTC settlement | `MIN_HOURS_TO_EXPIRY` (default 2 h); expiries parsed as real datetimes, not sliced strings |
| 6 | HIGH | No 429 / `SignatureExpired` / 5XX handling; `_public_get` ignored `success:false` | Typed `DeltaRateLimited` (honours `X-RATE-LIMIT-RESET`) and `DeltaAuthError` (never retried, carries client IP); one signature retry; jittered 5XX backoff; engine sleeps off rate limits |
| 7 | HIGH | Settled options booked at last quote — or **entry price**, recording worthless expiries as break-even | `_settlement_value()` computes true intrinsic against live spot; books 0 when spot is unavailable |
| 8 | HIGH | A failed candle fetch permanently skipped that bar's signals | Fetch first, consume the bar gate only for timeframes that returned data; use max lookback per timeframe |
| 9 | HIGH | `reconcile()` logged divergence but never repaired it, then suppressed the repeat | Ghosts booked closed; orphans journalled every check and flattened with `reduce_only` (`AUTO_FLATTEN_ORPHANS`) |
| 10 | HIGH | Backtest entered at `closes[i]` — the signal bar's own close (look-ahead) | Entry moved to `opens[i+1]`; exit scan starts at the entry bar so a gap through the stop counts |
| 11 | HIGH | One global `ChainStreamer` — a second tab's selection silently switched the first tab's chain | Reference-counted registry keyed by `(asset, expiry)`; frames carry their `key` |
| 12 | HIGH | Shutdown never flattened or reported open positions | Live positions flattened (`FLATTEN_ON_SHUTDOWN`); paper positions journalled loudly |
| 13 | HIGH | `bus.bid()` silently returned mark price — paper P&L collected ~half the spread as phantom profit | Bid means bid. Added separate `ask()` / `mark()`. `live_price()` returns `None` when genuinely unsellable |

Also fixed: correct spot in the fee model (#14/#15), strategy-declared
`limit_offset_pct` now honoured instead of silently ignored (#16), guard
ordering before negative indexing in all 9 strategies (#17/#18), Supertrend
negative-index reliance (#19), SQLite connection leak on every read (#20),
unbounded journal `limit` (#21), option chain now uses `EXEC_BASE` (#22),
candle pagination past Delta's 2000-bar cap (#23), no more guessed
`contract_value` default (#24), bounded price cache (#30).
